Sistema de Tickets - Unidad 3

Este proyecto es una aplicación web desarrollada con HTML, Bootstrap y JavaScript (Vue 3).

Cómo ejecutar el proyecto localmente:

1. Descargar o clonar el repositorio.
2. Abrir la carpeta del proyecto.
3. Ejecutar el archivo index.html en cualquier navegador web.

No requiere servidor, ya que funciona completamente del lado del cliente.

URL publicada en GitHub Pages:
https://elzejem.github.io/sistematickets/
